# Calculator App

A simple and interactive calculator web application built using HTML, CSS, and JavaScript.

This project supports both button clicks and keyboard input for calculations.

---

## 📌 Features
- Basic arithmetic operations (+, −, ×, ÷, %)
- Decimal number support
- Clear (C) and Delete (DEL) buttons
- Keyboard input support
- Error handling for invalid expressions
- Clean and responsive UI

---

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

---

## 🎯 What I Learned
- DOM manipulation
- Event handling (click & keyboard events)
- String manipulation (`slice`)
- Keyboard event handling
- UI styling using CSS Flexbox

---

## 🚀 How to Run the Project
1. Clone the repository
2. Open `index.html` in your browser
3. Start calculating
